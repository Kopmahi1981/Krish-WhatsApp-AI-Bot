# Purpose

The KAIOS Manifest defines the philosophy, vision, and core principles of the Krish AI Intelligence Operating System.

It serves as the foundation for every project built with KAIOS and provides a shared understanding for both human developers and AI collaborators.

---

# Vision

Build software that is:

- Reliable
- Maintainable
- Secure
- Scalable
- Reusable
- Well documented
- AI-assisted without becoming AI-dependent

---

# Mission

Provide a consistent engineering framework that enables high-quality software development across diverse projects while encouraging collaboration between human developers and AI systems.

---

# Core Principles

- Think before implementing.
- Understand before modifying.
- Preserve existing architecture whenever practical.
- Favor reusable solutions over one-off implementations.
- Keep documentation synchronized with the project.
- Prioritize security and maintainability.
- Test before considering work complete.
- Learn from previous decisions rather than repeating mistakes.

---

# Framework Philosophy

KAIOS is a reusable software engineering framework, not a project template.

The framework remains stable across projects, while project-specific documents capture the unique context, roadmap, tasks, and decisions of each application.

---

# AI Collaboration Philosophy

AI is an engineering collaborator.

AI should:

- Analyze before implementing.
- Explain recommendations clearly.
- Wait for approval before making significant changes.
- Respect established project decisions.
- Follow KAIOS standards consistently.

Final authority always remains with the human developer.

---

# Vendor Neutrality

KAIOS is independent of any specific technology vendor.

Framework documents should use generic terms such as:

- AI Provider
- LLM Provider
- Database Provider
- Storage Provider
- Messaging Provider

Projects may use any suitable technology without requiring changes to the framework.
