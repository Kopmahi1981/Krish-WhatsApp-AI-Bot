# Purpose

This document contains reusable, high-quality prompts for AI systems used throughout the project.

The objective is to maintain consistency, improve productivity, and reduce repetitive prompt writing across different AI tools.

---

# Startup Prompt

Use this prompt when starting a new AI session:

Read the following KAIOS documents before performing any analysis or implementation:

- KAIOS_MANIFEST.md
- UNIVERSAL_STARTUP_PROMPT.md
- GUARDRAILS.md
- PROJECT_CONTEXT.md
- ARCHITECTURE_GUIDELINES.md
- CODING_STANDARDS.md
- AI_PROTOCOL.md
- AI_MEMORY.md
- DECISIONS.md
- TASKS.md

After reading them:

1. Summarize your understanding.
2. Identify risks.
3. Suggest improvements.
4. Wait for approval before implementation.

# Code Review Prompt

Review the provided code for:

- Correctness
- Maintainability
- Security
- Performance
- Readability
- Best practices

Explain findings and recommend improvements.

---

# Bug Investigation Prompt

Analyze the reported issue.

Identify:

- Root cause
- Reproduction steps
- Possible solutions
- Risks
- Recommended fix

Wait for approval before modifying code.

---

# Feature Development Prompt

Understand the requested feature.

Explain:

- Requirements
- Impact
- Dependencies
- Design approach
- Risks

Produce an implementation plan before writing code.

---

# Refactoring Prompt

Review the existing implementation.

Recommend improvements while preserving functionality.

Avoid unnecessary architectural changes.

---

# Documentation Prompt

Generate clear technical documentation including:

- Purpose
- Usage
- Dependencies
- Examples
- Maintenance notes
